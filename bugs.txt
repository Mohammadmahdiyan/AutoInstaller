16. یک key value جدید داخل config.json میخام
به اسم require برای اینکه بعضی از مد ها برای اینکه اجرا بشه به یک (و requires برای برسی چند مد ) مد نیاز دارن 
که چند مقدار میگیره 
checkFile <= این کی میگه قبل از اینکه ریکوایر نصب بشه این فایل رو برسی کن اگر وجود نداشت باید مد نصب بشه اگر وجود داشت باید بره checkFolder رو برسی کنه
checkFolder <= این میگه قبل از اینکه نصب بشه برسی کن که همچین پوشه هایی نصب هستن یا نه اگر نصب نبودن باید ریکوایر نصب بشه اگه وجود داشت این رو باید نادیده بگیره یا ایگنور کنه 
نکته ممکنه که نه احتمال خیلی زیاده برای یک ریکوایر تعداد چک فایل و چک فولدر بیشتر از یکی باشه اونجا باید چطوری بنویسیم
reqAddress <= ادرس ریکوایر برای اینکه اگر فایل یا پوشه پیدا نشد
مثلا ما وقتی مدی نصب میکنیم پشت صحنه این اتفاق میفته 
مثلا این 
```json
{}
```
پشت صحنه این اتفاق میوته 
```json
{
    "type": "putinmodloader",
    "require": { // <= اگر چند مورد بود باید بنویسه requires و بجای ابجکت براکت بزار
        "checkFiles": [ // <= اگر یک فایل میخواست برسی بشه استرینگ بجای براکت و بجای checkFiles نوشته باشه checkFile
            "cleo.asi",
            "modloader.asi"
        ],
        "checkFolders": [
            "cleo",
            "modloader"
        ],
        "reqAddress": "Scripts\\A1-MyReqFiles"
    }
}
```

(نکته اگر هم این وجود داشت هم ریکوایر اول باید این اجرا بشه بعدش ریکوایر چون به مشکل میخوره باید برنامه واسته این  انجام بشه بعدش ریکوایر بعدش مد )

```json
{
  "deleteThis": {
    "file": "", // <= این فایل رو پاک کن
    "files": ["xxxxx", "xxxxx"], // <= این فایل ها رو پاک کن
    "folder": "", // <= این فولدر رو پاک کن
    "folders": ["xxxxx", "xxxxx"], // <= این فولدر ها رو پاک کن
    "replaceWith": "", // <= با این مد جایگزینش کن
    "replacesWith": "" // <= با این مد ها جایگزینش کن
  }
}
```
