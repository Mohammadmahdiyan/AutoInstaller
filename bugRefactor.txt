5. PutAndReplace : 
'در این تایپ میگه تمام فایل های جایگزینی پوشمو مد رو جایگزین میکنی 
فقط اونایی رو که من میگم ازشون بکاپ میگیری یا نمیگیری' باقی همینطوری جایگزین بشن مثلا

Base Mods Address\Cleo scripts\Ben10\
    modloader\Ben10 Mod\...
    models\hud.txd
    bass.dll
    gta_sa.exe
    modloader.asi
    vorbisFile.dll
    vorbisHooked.dll
    Z-ReadMe.txt
    mod.modsyn

```modsyn
mod {
    type: PutAndReplace,
    backup: some,
    backupThese: [
        "models\\hud.txd",
        "vorbisFile.dll",
        "vorbisHooked.dll"
    ]
}
``` 
(
توضیحات کاربرد و منطق تایپ
backupThis => این کی میگه از همه فایل یا پوشه هایی که توی مد هست توی بازی هم هست فایل های بازی که میخاد جایگزینشون بشه از همشون بک اپ نگیر بجز این فایل یا پوشه
backupThese => اینم دقیقا مثل قبلی فقط بجای یک مقدار چند مقدار میگیره
dontBackupThis => این کی میگه از همه فایل یا پوشه هایی که توی مد هست توی بازی هم هست فایل های بازی که میخاد جایگزینشون بشه از همشون بک اپ بگیر بجز این فایل یا پوشه
dontBackupThese => اینم دقیقا مثل قبلی فقط بجای یک مقدار چند مقدار میگیره
)

و نکته بعدی اینکه این چهار کی بالا که گفتم از فایل های اصلی بازی بک اپ میگیرن اگر بود لیست فایل های بازی رو گذاشتم اگر نیاز بود

و این مختص modloader.asi و فایل های داخل reqFiles نیست منظورم هر فایلی که داخل خود بازی هست و میخاد جایگزینش بشه بود

6. PutAndReplaces: این تایپ مثل تایپ قبلی ولی چند تا تفاوت مهم داره
اول از همه توی این تایپ واجب و اجباری نیست حدعقل یکی  از اینها باشه
1.backupThis
2.backupThese
3.dontBackupThis
4.dontBackupThese
و اصل این تایپ بنا شده بر اینکه 
'ببین من برام مهم نیست بنویسی یا ببنویسی چیو بک اپ بگیرم یا چیو بک اپ نگیرم چون من معمولا برای مد هایی استفاده میشم که فایل های زیادی دارن و 
نوشتن اینکه چیو بک اپ بگیری و چیو بک اپ نگیری سخته میتونه باشه ها ولی میتونه هم نباشه من خودم خودکار برسی میکنم چه فایلی میخاد جایگزین بشه خودم بک اپ میگیرم و فایل هایی که نمیخاد جایگزین بشه همینطوری میریزم'
مثلا 

Base Mods Address\Cleo scripts\Ben10\
    modloader\Ben10 Mod\...
    models\hud.txd
    bass.dll
    gta_sa.exe
    modloader.asi
    vorbisFile.dll
    vorbisHooked.dll
    Z-ReadMe.txt
    mod.modsyn

```modsyn
mod {
    type: PutAndReplaces,
}
```
