اینم دقیقا مثل قبلیه تفاوت فقط در step 5 هست 
این تایپ برای اینکه 
1. دو تا سیو یا بیشتر نصب کنیم
2. دو تا مرحله یا بیشتر نصب کنیم

13. میخام یک key value به modsyn اضافه کنم 
که فقط مخصوص 
MissionDSL
SaveAndMission
SavesAndMissions
هست اینطوری که بعضی وقتا هست میخاد غیر از مرحله میخاد یکچزای دیگه هم نصب بشه در user file 

```modsyn
mod {
    type: DSL,
    addToUserFile: [
        {
            from: "JLNSJ", // => منظورش اینکه داخل پوشه مد یک پوشه JLNSJ هست بریز توی to
            to: "" // => \Documents\GTA San Andreas User Files\ => (اینجا منظورشه) (اگر to نبود هم منظورش همینجاست)
        },
        {
            fromBase: "Scripts\\DYOM\\Dyom IX Addon TR Yama By Eren Unal Fix v3\text.gxt", // => Base Mods Address\ (این برای اینکه از ادرس بیس خواسته باشن یک چیزی رو نصب کنن)
            to: "MPACK" // => \Documents\GTA San Andreas User Files\MPACK\ (text.gxt رو اینجا باید بریزه)
        }
    ]
}
```
باید from باشه
باید مقدار داشته باشه
باید یا from باشه یا fromBase

13. Mixed
این تایپ هم میخام اضافه کنی 
مخفف : MIX
این تایپ برای اینکه ترکیبی چند تا مد با تایپ های مختلف رو نصب کنیم  مثلا 
Base Mods Address\Skins\Army-and-animation
    gta3img\
        male01.dff
        male01.txd
    animations\
        anim\anim.ifp

```modsyn
mod {
    type: mixed,
    list: [
        {
            type: VSW,
            folderName: "gta3img"
        },
        {
            type: Replacing,
            folderName: "animations"
            backup: none
        }
    ]
}
```
(نکته list باید حدعقل دو یا بیشتر ایتم بگیرهوگرنه خطا بده 
و folderName برای mixed برای تمام ابجکت ها واجب هست 
تایپ mixed واجب که List رو داشته باشه و list هم واجبه که حدعقل دو ایتم داشته باشه و واجبه داخل هر ابجکت folderName باشه
)
یکی یکی نصب میکنه ولی step 6 نمیره 
اولی رو نصب میکنه میره دومی تا اخر 

و برای حدف کردنش

بگه مد قبلا وجود داره میخای دوباره نصب کنی یا حذف کنی 
اگه گفت حذف کنی 
بیاد step 5 ولی step 5 مخصوص mixed من منظورمو با این فایل اچ تی ام ال ظاهرشو کامل توضیح دادم
