# 10. MOD NAME MUST COME FROM THE MOD FOLDER

The application must NOT require the mod name inside config.json.

The mod name comes from the folder containing `config.json`.

Example:

```text
Mini pack object gta v\
    config.json
    object gta v\
```

Display name:

```text
Mini pack object gta v
```

If the folder is:

```text
1987654-Mini-pack_object gta v\
    config.json
```

the displayed mod name should be:

```text
Mini pack object gta v
```

Therefore implement a clean mod-name normalization function.

It should remove a leading numeric ID/prefix such as:

```text
1987654-
```

and convert underscores to spaces where appropriate:

```text
Mini-pack_object gta v
```

→

```text
Mini pack object gta v
```

Do NOT remove meaningful words.

The actual source folder must remain unchanged.

This normalization is only for display.

# 11. MOD CONTENT / INSTALLATION

The folder containing `config.json` is the package root.

Example:

```text
Maps\
└── Mini pack object gta v\
    ├── config.json
    └── object gta v\
        ├── model.dff
        ├── model.txd
        └── ...
```

The actual ModLoader payload is:

```text
object gta v\
```

It must be copied into:

```text
<GTA SA>\modloader\
```

Result:

```text
<GTA SA>\
└── modloader\
    └── object gta v\
        ├── model.dff
        ├── model.txd
        └── ...
```

Do NOT copy:

```text
config.json
```

into ModLoader.

`config.json` is metadata for this Mod Manager.

Do not install README files, screenshots, previews, or metadata files unless they are actually part of the payload.
