6. Replacing : 
کلید `backup` را برای تایپ‌های زیر می‌خواهم:
Replacing,
PutAndReplace,
PutAndReplaces
تایپ های جایگزینی 
mod {
    type: Replacing,
    backup: all
}
مقدار پیش‌فرض `backup` برابر `all` است؛ یعنی از همه فایل‌های جایگزین‌شونده Backup گرفته شود. مقدار `none` Backup را غیرفعال می‌کند. مقدار `some` یعنی Backup بر اساس کلیدهای انتخاب مسیر که در ادامه آمده‌اند محدود شود. در این زبان از `null` برای این حالت استفاده نمی‌شود.
backupThis : مقدار استرینگ میگیره و میگه فقط این فایل یا فقط این پوشه رو بک اپ بگیره
backupThese : مقدار براکت میگیره و میگه فقط این فایل ها یا این پوشه ها یا ترکیبشون رو بک اپ بگیره
dontBackupThis : مقدار استرینگ میگیره و میگه فقط این فایل یا این پوشه رو بک اپ نگیره
dontBackupThese : مقدار براکت میگیره و میگه فقط این فایل ها یا این پوشه ها یا ترکیبشون رو بک اپ نگیره

کلیدهای `backupThis` و `backupThese` مسیرهای مشمول Backup را مشخص می‌کنند؛ `dontBackupThis` و `dontBackupThese` مسیرها را مستثنا می‌کنند و بر انتخاب‌های Backup اولویت دارند. هنگام استفاده از هرکدام از این چهار کلید، مقدار `backup` باید `some` باشد و دست‌کم یک مسیر انتخاب شود.

مثلا
Base Mods Address\Sounds\original audio\
    config.modsyn
    audio\
        Config\
        SFX\
        Streams\
    cleo\
        cleo5.asi
در فایل ModSyn پکیج، مثلاً `config.modsyn`:
```modsyn
mod {
    type: PutAndReplaces,
    backup: some,
    dontBackupThese: [ 
        "audio\\Config", 
        "audio\\SFX",
        "cleo\\cleo5.asi"
    ]
}
```
