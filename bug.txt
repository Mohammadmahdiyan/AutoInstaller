6. Replacing : 
یک key value میخام به مختض تایپ های 
Replacing,
PutAndReplace,
PutAndReplaces
تایپ های جایگزینی 
{
    "type": "Replacing",
    "backup": true
}
backup یعنی ایا بک اپ گرفته بشه اگع true بود بگیره اگر false نگیره مقدار دیفالتش true 
اما یک مقدار دیگه باید بگیره null که این برای اینکه کی ولیو باقی رو بگیره
backupThis : مقدار استرینگ میگیره و میگه فقط این فایل یا فقط این پوشه رو بک اپ بگیره
backupThese : مقدار براکت میگیره و میگه فقط این فایل ها یا این پوشه ها یا ترکیبشون رو بک اپ بگیره
dontBackupThis : مقدار استرینگ میگیره و میگه فقط این فایل یا این پوشه رو بک اپ نگیره
dontBackupThese : مقدار براکت میگیره و میگه فقط این فایل ها یا این پوشه ها یا ترکیبشون رو بک اپ نگیره

مثلا
Base Mods Address\Sounds\original audio\
    config.json
    audio\
        Config\
        SFX\
        Streams\
    cleo\
        cleo5.asi
در فایل جیسون
```json
{
    "type": "PutInReplace"
    "backup": null,
    "dontBackupThese": [
        "audio\\Config",
        "audio\\SFX"
        "cleo\\cleo5.asi"
    ]
}
```
و خروجی
Game Address\
    .ModManager\
        backup\
            original audio\
                streams\
    cleo\
        cleo5.asi
    audio\
         Config\
         SFX\
