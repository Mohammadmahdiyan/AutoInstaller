# Buttons and Previews

- **Previous** returns to the previous wizard step. In multi-model asset selection, it returns to the previous model or to Step 3 from the first model.
- **Next / Install** advances the wizard. Its label and action depend on the current step and package type; in Step 5 it confirms the selected mapping or starts the next model.
- **Browse** opens a folder picker for the game folder, Base Mods folder, or mod package, depending on where it appears.
- **README** opens the selected package's README file when one is available. A README may also appear as text in the sidebar.
- **Image navigation** arrows move between package preview images when more than one image is available. Right-clicking a preview can open the image viewer.

Step 6 also provides actions such as opening the game folder, launching the game, and starting another mod-manager session.
