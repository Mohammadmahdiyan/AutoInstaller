# Keyboard Shortcuts

| Function | Shortcut |
| --- | --- |
| Next button (sidebar) | `Enter` |
| Previous button (sidebar) | `Esc` |
| Activate search box (Step 5 VSW/VSS) | `Ctrl + F` |
| Open Game Folder (Step 6) | `Ctrl + Shift + G` |
| Open GTA San Andreas User Files (Step 6) | `Ctrl + Shift + U` |
| Run Game (Step 6) | `Ctrl + Shift + R` |
| Install more mods (Step 6) | `Ctrl + Shift + M` |
| Browse (Steps 1-3) | `Ctrl + O` |
| Next gallery photo (Step 3, when paging is available) | `Right Arrow` |
| Previous gallery photo (Step 3, when paging is available) | `Left Arrow` |
| Open image gallery (Steps 3-6, when media is available) | `Space` |
| Close image gallery | `Esc` |
| Toggle gallery sound (while a video is open) | `M` |
| Change to next language | `Ctrl + Shift + L` |
| Change to next theme | `Ctrl + Shift + T` |
| Mod Status (Step 5 VSS/SAM) | `Ctrl + Shift + S` |
| Keep Original Name (Step 5 VSS) | `Ctrl + Shift + K` |
| Skip This Model (Step 5 VSS) | `Ctrl + Shift + X` |
| Finish Here - Install Checked Models Only (Step 5 VSS) | `Ctrl + Shift + Enter` |
| Install Unchecked Models as Named (Step 5 VSS) | `Ctrl + Shift + N` |
| Change to next category (Step 5 VSW/VSS) | `Alt + Down Arrow` |
| Change to next column count (Step 5 VSW/VSS) | `Alt + C` |
| Change to next sort mode (Step 5 VSW/VSS) | `Alt + S` |
| Open README (sidebar) | `Ctrl + Shift + D` |
| Select Vehicle (asset type dialog) | `Alt + V` |
| Select Skin (asset type dialog) | `Alt + K` |
| Select Weapon (asset type dialog) | `Alt + W` |
| Next item (asset type dialog) | `Alt + Right Arrow` |
| Cancel (asset type dialog) | `Esc` |
| Continue (asset type dialog) | `Enter` |
