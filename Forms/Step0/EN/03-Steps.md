# Wizard Steps

1. **Step 1 — Game folder:** choose and validate the GTA San Andreas installation.
2. **Step 2 — Base Mods folder:** choose your source package library.
3. **Step 3 — Select mod:** browse to the package folder; the manager reads its manifest and previews available README and media files.
4. **Step 4 — Installation progress:** shows progress and files while an install or delete operation runs.
5. **Step 5 — Asset selection:** choose which catalog vehicle, skin, or weapon a model replaces. Multi-model packages show one model at a time; review its mapping before continuing.
6. **Step 6 — Completion:** confirms the operation and provides game-folder, launch, or install-more actions where available.

Not every package type uses every step. For example, a package that does not require asset selection can proceed directly from Step 3 to installation.
