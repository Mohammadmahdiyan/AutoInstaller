# Game and Mod Folders

**Game folder** is the GTA San Andreas installation directory containing `gta_sa.exe`. The manager uses it as the install target and creates or uses its `modloader` and `cleo` folders when needed.

**Base Mods folder** is your library of source packages. Choose the folder that contains your organized mod collections. In Step 3, browse to the individual package folder you want to use.

Example:

```text
H:\Games\GTA San Andreas\
  gta_sa.exe
  modloader\

H:\Mods\
  Cars\
    RZL Trainer\
      config.json
      RZL Trainer.cs
```

The package folder is the mod address. The game folder and Base Mods folder are separate locations.
