# میانبرهای صفحه‌کلید

| عملکرد | میانبر |
| --- | --- |
| دکمهٔ بعدی نوار کناری | `Enter` |
| دکمهٔ قبلی نوار کناری | `Esc` |
| فعال‌کردن جستجو (مرحلهٔ ۵، VSW/VSS) | `Ctrl + F` |
| بازکردن پوشهٔ بازی (مرحلهٔ ۶) | `Ctrl + Shift + G` |
| بازکردن فایل‌های کاربر GTA San Andreas (مرحلهٔ ۶) | `Ctrl + Shift + U` |
| اجرای بازی (مرحلهٔ ۶) | `Ctrl + Shift + R` |
| نصب مودهای بیشتر (مرحلهٔ ۶) | `Ctrl + Shift + M` |
| انتخاب پوشه (مراحل ۱ تا ۳) | `Ctrl + O` |
| عکس بعدی گالری (مرحلهٔ ۳، در صورت وجود صفحه‌بندی) | `Right Arrow` |
| عکس قبلی گالری (مرحلهٔ ۳، در صورت وجود صفحه‌بندی) | `Left Arrow` |
| بازکردن گالری تصاویر (مراحل ۳ تا ۶، در صورت وجود رسانه) | `Space` |
| بستن گالری تصاویر | `Esc` |
| روشن/خاموش‌کردن صدای گالری (هنگام نمایش ویدیو) | `M` |
| رفتن به زبان بعدی | `Ctrl + Shift + L` |
| رفتن به تم بعدی | `Ctrl + Shift + T` |
| وضعیت مود (مرحلهٔ ۵، VSS/SAM) | `Ctrl + Shift + S` |
| حفظ نام اصلی (مرحلهٔ ۵، VSS) | `Ctrl + Shift + K` |
| ردکردن این مدل (مرحلهٔ ۵، VSS) | `Ctrl + Shift + X` |
| پایان و نصب مدل‌های تیک‌خورده (مرحلهٔ ۵، VSS) | `Ctrl + Shift + Enter` |
| نصب مدل‌های تیک‌نخورده با نام اصلی (مرحلهٔ ۵، VSS) | `Ctrl + Shift + N` |
| رفتن به دستهٔ بعدی (مرحلهٔ ۵، VSW/VSS) | `Alt + Down Arrow` |
| رفتن به تعداد ستون بعدی (مرحلهٔ ۵، VSW/VSS) | `Alt + C` |
| رفتن به روش مرتب‌سازی بعدی (مرحلهٔ ۵، VSW/VSS) | `Alt + S` |
| بازکردن README از نوار کناری | `Ctrl + Shift + D` |
| انتخاب وسیلهٔ نقلیه (پنجرهٔ انتخاب نوع مدل) | `Alt + V` |
| انتخاب اسکین (پنجرهٔ انتخاب نوع مدل) | `Alt + K` |
| انتخاب اسلحه (پنجرهٔ انتخاب نوع مدل) | `Alt + W` |
| رفتن به مورد بعدی (پنجرهٔ انتخاب نوع مدل) | `Alt + Right Arrow` |
| لغو (پنجرهٔ انتخاب نوع مدل) | `Esc` |
| ادامه (پنجرهٔ انتخاب نوع مدل) | `Enter` |
